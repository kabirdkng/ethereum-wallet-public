# Language Switcher - User Guide

## How to Change Language

### Step 1: Find the Language Switcher
Look for the language selector in the **top-right corner** of every page. It shows a flag and language name (e.g., "🇺🇸 English").

### Step 2: Click to Open
Click on the language selector to see all available languages:
- 🇺🇸 English
- 🇫🇷 Français (French)
- 🇭🇹 Kreyòl Ayisyen (Haitian Creole)
- 🇪🇸 Español (Spanish)

### Step 3: Select Your Language
Click on your preferred language. The page will instantly update to show content in that language.

## What Changes When You Switch Languages

### ✅ Translated Elements
- App title: "Ethereum Wallet" → "Bous Ethereum" (Haitian Creole)
- Buttons: "Send Money" → "Enviar dinero" (Spanish)
- Headings: "My Wallet" → "Mon portefeuille" (French)
- Menu items and navigation
- Section labels

### ⚠️ Elements That Stay the Same
- Wallet addresses (blockchain data)
- Transaction hashes
- Numbers and amounts
- User email/phone
- Some technical terms

## Language Persists Across Pages

Once you select a language:
1. It applies to ALL pages in the app
2. When you navigate (home → dashboard → send money), your language choice is preserved
3. The URL includes your language (e.g., `/fr/dashboard`)

## Troubleshooting

### Language Not Changing
- Make sure you clicked on a different language in the dropdown
- Try refreshing the page
- Check that the URL includes your language code (e.g., `/es/`)

### Mixed Languages
- This is normal during the transition period
- Some components are still being translated
- Main features (wallet, send, receive) are already translated

### Wrong Language on Start
- The app detects your browser's language preference
- You can always change it using the language switcher
- Your choice is saved in the URL

## Need Help?

If you encounter issues with language switching:
1. Check the URL - it should include your language code
2. Try manually navigating to your preferred language (e.g., change `/en/` to `/fr/`)
3. Clear your browser cache if the language doesn't persist
